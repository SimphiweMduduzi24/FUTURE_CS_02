
# Phishing Email Detection & Awareness System

## Internship
Future Interns – Cyber Security Internship Program

## Task
Task 2 – Phishing Email Detection & Awareness System

## Project Overview
This project focuses on identifying and analysing phishing emails to understand how cybercriminals use email to deceive individuals and organisations.

The project aims to identify suspicious email characteristics, classify emails based on their risk levels, and provide recommendations to help users protect themselves against phishing attacks.

## Objectives
- Identify suspicious email senders.
- Examine suspicious links and domains.
- Recognise phishing techniques and social engineering tactics.
- Classify emails as Safe, Suspicious, or Phishing.
- Develop cybersecurity awareness and prevention guidelines.

## Tools and Technologies
- Email Header Analyzer
- Browser Developer Tools
- Public phishing email samples
- GitHub
- Microsoft Word / Google Docs

## Project Structure
- phishing_samples/ – Sample emails used for analysis.
- analysis/ – Investigation findings and classifications.
- screenshots/ – Evidence of project activities.
- report/ – Final phishing detection and awareness report.

## Expected Deliverables
A professional Phishing Detection & Awareness Report containing email examples, identified phishing indicators, risk explanations, and prevention recommendations.

## Disclaimer
All examples used for this project are intended for educational purposes. No real phishing links will be opened or interacted with.
